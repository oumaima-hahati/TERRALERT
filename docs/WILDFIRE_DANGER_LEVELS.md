
# TERRALERT — Wildfire Danger Levels

## 1. Objective

Define wildfire danger categories for the 11 TERRALERT communes using the Fire Weather Index (FWI).

## 2. Classification

| FWI Value | Danger Level |
|---|---|
| < 5.2 | Very Low |
| 5.2 – < 11.2 | Low |
| 11.2 – < 21.3 | Moderate |
| 21.3 – < 38.0 | High |
| 38.0 – < 50.0 | Very High |
| >= 50.0 | Extreme |

## 3. Required Data

- Air temperature (°C)
- Relative humidity (%)
- Wind speed (km/h)
- 24-hour precipitation (mm)

## 4. Application in TERRALERT

Each commune will receive a wildfire danger category based on its calculated FWI.

The categories will later be displayed on the interactive map.

## 5. Limitations

These thresholds are provisional and require local validation.

FWI measures weather-related fire danger, not confirmed fire occurrence. NASA FIRMS detections will be displayed separately.
